# 퇴사 라벨과 모델 모드

라벨이 있으면 규칙 기반 지수 대신 예측 모델(로지스틱 회귀)을 학습한다.

## 넣는 방법

1. 워크북에 `퇴사라벨`(또는 `labels`) 시트를 추가한다.
2. 또는 직원 명부 한 장 모드에서 `퇴사여부`(left) 컬럼을 둔다.
3. 또는 별도 CSV를 `--labels` 옵션으로 넘긴다.

| 컬럼 | 필수 | 값 |
|---|---|---|
| `employee_id`(사번) | 예 | 분석 대상 직원의 사번 |
| `left`(퇴사여부) | 예 | `1`/`0`, `true`/`false`, `예`/`아니오`, `퇴사`/`재직` |
| `left_date` | 아니오 | 퇴사일(참고용) |

## 조건과 동작

- 양성(퇴사)·음성(재직) 각 10명 이상이어야 학습한다. 모자라면 `auto` 모드는 규칙 지수로 대체하고 `summary.json`의 `fallback_reason`에 사유를 적는다.
- 라벨이 없는 사번은 학습에서 빠지고 점수만 받는다.
- 알고리즘: 결측 중앙값 대치 → 표준화 → 로지스틱 회귀(class_weight=balanced, C=0.5). 층화 교차검증(최대 5겹) AUC와 계수를 `metrics.json`에 기록한다.
- scikit-learn이 없는 환경에서는 모델 모드가 실패하고 `auto`는 규칙 지수로 대체한다.

## 라벨 만들 때 흔한 실수

- "현재 재직자 명단"만으로는 라벨을 만들 수 없다. 과거 시점 재직자 중 이후 퇴사한 사람이 있어야 한다.
- 퇴사 사유가 정년·계약 만료인 경우를 자발적 이직과 섞으면 모델이 엉뚱한 신호를 배운다. 가능하면 자발적 퇴사만 1로 둔다.
