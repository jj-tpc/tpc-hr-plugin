# /make_dashboard — 현황 + 예측 결과 대시보드

`scripts/make_dashboard.py`로 단일 HTML "HR 리스크 터미널"을 만든다. 외부 리소스가 없어 오프라인·아티팩트 어디서나 열린다.

- **상단 상태줄**: 회사·기준일·분석 모드(진단/예측)·입력 파일·엔진 버전·방법론 6단계 상태등(Q D H V A R)·검색(`/`)·공유용 토글(`s`, 이름·사번 가림).
- **좌측 레일**: 위험 '높음' 인원(히어로 숫자), 본부>팀 트리(인원·높음 수·평균 위험 히트셀). 클릭하면 모든 패널이 그 조직으로 **표시 필터**된다(재계산 없음).
- **신호 보드**: 선택 범위의 신호별 평균, 회사 대비 σ, 분포 스파크바, '높음' 그룹의 위험 방향 z. 모델 계수 방향이 가설과 다른 신호는 ≠ 표시.
- **가설 H1~H9**: 판정 칩(지지/불명확/탐색적 증거)과 단변량 AUC 바.
- **팀 × 신호 히트맵**: 팀 평균 z를 위험 방향으로 부호 정렬해 빨강(위험 쪽)·파랑(안전 쪽)·회색(평균)으로. 어느 팀이 어떤 신호에서 뜨거운지 한 장에.
- **워치리스트**: 위험 순 직원 표(정렬·검색), 최근 6개월 연장근로 스파크라인(원본이 있을 때), 평이한 주요 신호, "확인함" 체크(브라우저에만 저장). `↑↓`로 이동, `Enter`로 상세.
- **검증 V1~V9 · 회사 신호→조치 · 팀별 확인사항**: 결과 엑셀의 시트를 그대로 가져온다.
- **구성 · 월별 추세**: 근속·직급·고용형태 소형 막대, 월평균 연장근로 선·지각 막대(기준일 이후 월 제외), 설문 차원 1~5 막대와 eNPS.
- **하단 드로어**: 선택 직원의 신호별 회사 평균 대비 불릿(위험 방향 z), 주요 신호, 값의 출처 테이블, 읽을 때 주의.

## 입력

| 상황 | 명령 |
|---|---|
| 결과 엑셀 + 원본 HR 엑셀 둘 다 첨부(권장) | `--result <퇴사위험_결과.xlsx> --data <HR.xlsx>` |
| 결과 엑셀만 첨부 | `--result <퇴사위험_결과.xlsx>` (현황 탭은 결과 파일 안의 정보로만 그린다. 월별 근태·설문 카드는 비어 있고 그 이유가 표시된다) |
| 원본 HR 엑셀만 첨부 | `--data <HR.xlsx>` (예측을 먼저 수행하고 대시보드를 만든다. 결과 엑셀도 함께 생긴다) |

결과 엑셀은 `/predict_attrition`이 만든 것이어야 한다(`_data`, `_meta` 시트 포함). 아니면 스크립트가 그렇게 말하며 멈추므로 사용자에게 `/predict_attrition`을 먼저 안내한다.

## 절차

1. 첨부 파일을 확인하고 위 표에서 명령을 고른다.
2. 실행한다.

```bash
python <이 스킬 폴더>/scripts/make_dashboard.py --result <결과.xlsx> --data <원본.xlsx> --out <출력 폴더>
```

3. `dashboard.html`을 읽어 HTML 아티팩트로 보여준다(아티팩트가 안 되면 파일로 전달). 외부 스크립트·CDN이 없어 어디서나 그대로 그려진다.
4. 읽는 법을 서너 문장으로 안내한다: 좌측 트리를 눌러 조직을 고르면 전부 연동된다는 것, 히트맵의 빨강은 "회사 평균보다 위험 쪽"이라는 것, 워치리스트 행을 누르면 아래 드로어에 신호별 비교가 뜬다는 것. 상태줄 배지가 "진단 모드 · 예측 아님"이면 "지수는 예측 확률이 아니라 신호를 모은 상대 순위이며 개인 조치의 단독 근거가 아니다"라고 한 문장 덧붙인다. 원본 없이 만들었으면 원본을 함께 주면 월별 추세·스파크라인·설문이 채워진다고 말한다. 기본 안내는 조직 단위로 하고, 개인 행은 요청이 있을 때만 다룬다.
5. 수치 질문이 오면 대시보드 안 숫자가 아니라 결과 엑셀의 `직원별 위험`·`팀별` 시트(또는 `_data`)를 읽어 답한다.

## 하지 않을 것

- 대시보드에 성별·국적·혼인 같은 민감 속성 차트를 추가하지 않는다. 요구가 있으면 공정성 문제를 한 줄로 알리고 거절한다.
- "퇴사 확률"이라는 말을 쓰지 않는다(모델 모드 제외).
