# /make_dashboard — 현황 + 예측 결과 대시보드

`scripts/make_dashboard.py`로 단일 HTML 대시보드를 만든다. 두 탭으로 구성된다.

- **인력 현황**: 재직·휴직·기간제·보직자·평균 근속·평균 나이·입사 1년 미만·연차 사용률 KPI, 본부별 인원, 직군 구성, 직급 분포, 근속 분포, 연령대, 고용형태. 원본 HR 파일이 있으면 월별 근태 추세(월평균 연장근로·지각)와 설문 차원별 평균(최근 2개 설문 비교)이 추가된다.
- **퇴사 위험**: 밴드 KPI, 위험 지수 분포, 본부·직군별 평균 위험, 근속 대비 산점도, '높음' 그룹의 주요 신호, 검색·정렬되는 직원 표(평이한 신호 표기), 직원 상세(신호 값과 회사 평균 대비 z).

## 입력

| 상황 | 명령 |
|---|---|
| 결과 엑셀 + 원본 HR 엑셀 둘 다 첨부(권장) | `--result <퇴사위험_결과.xlsx> --data <HR.xlsx>` |
| 결과 엑셀만 첨부 | `--result <퇴사위험_결과.xlsx>` (현황 탭은 결과 파일 안의 정보로만 그린다. 월별 근태·설문 카드는 비어 있고 그 이유가 표시된다) |
| 원본 HR 엑셀만 첨부 | `--data <HR.xlsx>` (예측을 먼저 수행하고 대시보드를 만든다. 결과 엑셀도 함께 생긴다) |

결과 엑셀은 `/predict_attrition`이 만든 것이어야 한다(`_data`, `_meta` 시트 포함). 아니면 스크립트가 그렇게 말하며 멈추므로 사용자에게 `/predict_attrition`을 먼저 안내한다.

## 절차

1. 첨부 파일을 확인하고 위 표에서 명령을 고른다.
2. 실행한다.

```bash
python <이 스킬 폴더>/scripts/make_dashboard.py --result <결과.xlsx> --data <원본.xlsx> --out <출력 폴더>
```

3. `dashboard.html`을 읽어 HTML 아티팩트로 보여준다(아티팩트가 안 되면 파일로 전달). Chart.js는 cdnjs에서 불러오므로 아티팩트 뷰어에서 그대로 그려진다.
4. 두 탭에 무엇이 있는지 두세 문장으로 안내하고, 상단 배지가 "규칙 기반 지수 · 예측 아님"이면 "퇴사 위험 탭의 지수는 예측 확률이 아니라 신호를 모은 상대 순위"라고 한 문장 덧붙인다. 원본 없이 만들었으면 원본을 함께 주면 근태 추세·설문 카드가 채워진다고 말한다.
5. 수치 질문이 오면 대시보드 안 숫자가 아니라 결과 엑셀의 `직원별 위험`·`팀별` 시트(또는 `_data`)를 읽어 답한다.

## 하지 않을 것

- 대시보드에 성별·국적·혼인 같은 민감 속성 차트를 추가하지 않는다. 요구가 있으면 공정성 문제를 한 줄로 알리고 거절한다.
- "퇴사 확률"이라는 말을 쓰지 않는다(모델 모드 제외).
